# eCommerce Website Builder – Responsive HTML/CSS/JS

This is a front-end landing page inspired by the current structure of the Wix eCommerce website builder page.

## Files

- `index.html` – page structure
- `style.css` – complete responsive styling
- `script.js` – mobile menu, dropdowns, search, feature switcher and template filtering

## Responsive targets

The CSS includes layouts for:
- Mobile S/M/L: below 620px
- Tablet: 621–900px
- Laptop: 901–1180px
- Large laptop/desktop: 1181–1799px
- 4K / very large screens: 1800px+

## Run

Open `index.html` directly in a browser.
